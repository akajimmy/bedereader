Image lab

Temporary tool for tuning the reader's page processing. The page is rendered as the chosen screen would show it (fit screen), one canvas pixel = one screen pixel. Left of the line: the baseline; right: your settings. Hold Space to see the baseline full width. Drag the line, or use the Split slider. Every step here is a GPU shader, so whatever is chosen runs on phones, tablets and desktop alike.
